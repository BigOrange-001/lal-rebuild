# 1.0.4 羁绊效果表

**技能输出调整：以下技能机制说明保留设计基准；伤害、护盾、治疗及其等级成长统一乘 0.8。属性增减益、控制时长、目标数量及羁绊面板加成保持原值。**

覆盖 124 个已具名英雄/皮肤身份，共 111 组，每个身份 2–3 组。排除解说、野怪、小兵、未具名模板及签到预览。

普通英雄和皮肤英雄分组；原则上同品质激活。仅在某成员最低品质为紫色时，允许该紫卡加入蓝卡组合。相同组的百分比效果不随品质变化；橙卡次级属性预算按人数为 6000/10000/15000/20000，其他品质按卡面总属性比例缩放。

只有上阵英雄获得羁绊加成。德诺已开启的全属性格子可补齐成员，其他格子不参与；好友队长携带其原阵容生成的羁绊快照。羁绊在开战时确定，不因队友阵亡而消失。

多组面板强化依次独立相乘，技能数值强化也相乘。同一英雄同时满足多个机制组时，以人数最多的一组为技能机制；同人数按组编号较大者优先，其余面板和技能数值加成保留。

设定参考：[英雄联盟宇宙·德玛西亚](https://universe.leagueoflegends.com/en_US/region/demacia/)及[源计划官方资料](https://www.leagueoflegends.com/en-us/news/tags/project-skins/)。地域/阵营组取世界观关联，定位组和同人组为本项目原创玩法设计，不代表官方已有羁绊或同一皮肤宇宙。

人数分布：双人 63 组，三人 29 组，四人 13 组，五人 6 组。新增 b102–b110。

各组仅在成员实际具有的品质激活；不存在的橙卡不会被补成跨品质组合。

设计约束：任意两组羁绊的成员集合不得相同，也不得互相完整包含。凑齐某一组时，不会同时自动凑齐它的子组合；新增或改组时由生成器和回归测试共同校验。

九英雄技能包和莫德凯撒皮肤身份调整后的组合见下表；新增「白蛇端阳」。包内技能先乘 2/3，再进入全局 0.8；详见 [英雄包接入说明](hero-packs-1.0.4.md)。
