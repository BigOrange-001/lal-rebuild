# 主线难度映射灵魂塔

普通第 1 章保持原样，第 2～5 章末关推荐战力线性提高至 20,000，实际依次为 6,925、10,192、13,463、16,733、20,000。普通第 6～30 章线性对应灵魂塔第 10～80 层；精英第 1～30 章线性对应第 10～125 层。以每章末关为锚点，章内各关相对末关的原实际战力比例保留。

映射层数允许小数，取相邻塔层实际战力的几何插值。使用最终英雄、技能及当前战力系数下序列化出来的真实敌方快照作为基准，再拟合主线敌人的生命、攻击、物防和魔防。因此修改会作用于实际战斗，不仅是推荐数字。

灵魂塔第 1～125 层推荐战力同步到当前快照口径，塔内敌人属性保持不变；第 126～180 层保持原配置。普通第一章、主线敌方阵容和站位、奖励、掉率、体力、挑战次数均保留。
