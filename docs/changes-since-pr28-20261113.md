# PR #28 之后的功能整合

基线为 `65c18b6`（PR #28）。版本仍为1.0.4。

- 新增神龙尊者卡莎、黑夜使者亚索六星皮肤的技能、资源、招募及离线模型；亚索最终大招175%/175%/444%、100%实际生命伤害吸血且不受精准加成、小技能一层净化及后排33%～66%攻击衰弱1回合。
- 新增3组皮肤英雄羁绊和4条本人装备属性羁绊。异界剑盟允许黑夜亚索在沉默时释放大招，并使三段大招伤害各按1.12倍结算，显示“伤害提升12%”。详见 `new-skin-bonds-20261113.md`。
- 奇遇累充新增30000元神龙尊者卡莎 `A_1801_6`、50000元黑夜使者亚索 `A_1802_6`，各发一张普通初始养成状态的橙卡。沿用历史名义充值额，不按钱包余额或首充翻倍数计算。每档终身限领一次；请求重试返回原回执，背包满则不标记已领取。已经达标的旧存档可直接领取，不补扣充值额。
- 实际客户端默认启用此前研究的比例伤害模型，设置中可选择旧版，从下一场战斗生效；研究脚本显式指定旧版对照，保留原生初始化倍率赋值接口。
- 血量与浅紫护盾联动，保留原版高光阴影。双方共用每25%最大生命值的连续刻度，超过满血继续划线并整体压缩；设置可显示仅生命值的当前/最大数字。
- 修复艾克回溯到已结束分路后消失；保留净化与按记录损失回血。
- 装备框按实际星级映射，补齐低品质装备进阶换色；7星红框、预留8星彩虹框、原版镶座阴影角饰、各处名称颜色统一及8星终阶保护。实际配置上限仍为7星。
- 操作回执无损压缩，兼容旧格式、重试、VIP历史和Mod实例编号恢复；纳入安卓单机管理器源码及构建入口，提供gzip存档、备份去重、最多5份自动备份与10 MiB合计预算，保留手动及导入存档。
- 收录独立英雄测试场与满配全卡测试工具，保留其隔离账号/存档规则。工具中的测试账号仅用于显式启动的测试服务，不注入正式单机运行资源。
- 研究入口识别两位新增英雄，当前研究池为134名（97普通、37皮肤）；原生研究桥同步新的伤害回执接口，避免研究过程中调用旧签名出错。
- 修复安卓管理器冷启动在主线程初始化Python造成卡顿的风险，以及导出文档选择期间界面重建后丢失所选存档的问题。

客户端新增 `ProgressBar` 阶段；构建顺序同时保证 `Equip` 在引用其新颜色方法的装备界面之前编译。编译产物、工具链、签名、玩家数据库和测试账号存档不纳入PR。

正式关卡、副本配置沿用PR #28基线；原始 `full-config.json` 与基线逐字节一致。正式单机入口启动普通gateway，打包的runtime不含训练服务入口，第一章不会替换为测试靶场。

验收结果见 `pr-validation-20261113.md`。Python定向回归需要服务端依赖；原生研究桥另外需要 `quickjs-ng`（本轮0.18.0.1），图形检查需要Pillow。已有安装记录属于对应冻结版本，不代表这次新加的累充档位已经安装到设备，也不代表本次从原始模板重跑了全部178阶段。
