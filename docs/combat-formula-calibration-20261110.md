# 战斗公式重做：服务端实现与首轮校准

2026-11-10。对应设计稿 `combat-formula-redesign-20261110.md` 的阶段 1、2。当前分支 `feat/combat-formula-redesign-20261110`，基线提交 `6cab382`。

**服务端新模型已经可以显式启用，默认仍为旧模型。首轮实测不支持直接定稿或切换默认值。** 0.66 初值改善了部分中期对位，但没有同时满足前期、裸装满级和毕业队的击杀次数要求。毕业队中瑞雯与冰鸟的普通技能差距、以及部分队长技超过 40% 生命的情况，不能靠同一个全局倍率解决。本轮没有调整任何英雄个体技能，没有进入敌人数值生成或客户端同步阶段。

## 已实现的服务端规则

`config/reconstruction/combat-rules-1.0.4.json` 提供参数，加载后合并到已有的 `cfg.combat_rules`，保留原有的治疗和分摊规则。`model=legacy` 是默认值。只有研究脚本显式构造 `model=ratio` 的配置副本时，候选参数才在离线战斗中生效；原 `system_simple.attack` 数组没有被覆盖。

| 项目 | 本轮实现 |
| --- | --- |
| 防御 | 三个伤害入口共用比例减伤函数，分母取攻击者 `ap`；有效防御仍走原破甲、钢铁及穿透逻辑 |
| 固定曲线 | p=1.5，c=0.7，减伤上限 90%；攻击为 0 时分母按 1 处理 |
| 四属性 | 闪避 8/35/40，暴击 15/60/60（基础值/上限/斜率）；固定 2 倍暴伤；韧性通用减伤系数 0 |
| 原生真伤 | 候选比例 0.5 |
| 预除比例的真伤技能 | 改读当前真伤比例并统一乘候选修正 0.8，避免把预除 0.3 的技能误增伤 |
| 全局伤害 | 候选 0.66；DOT 和护士固定反伤使用同一候选参数；治疗与护盾不乘它 |
| 兼容性 | 保留旧模型取整顺序，以及构造战斗后替换配置仍能生效的既有调用方式 |

曲线在防攻比 3 时为 89.87% 减伤，约 3.029 才真正触及上限；设计稿的“3 以上 90%”是近似表述，没有擅自提前截断。

默认配置差分验证：除新增的模型控制字段外，加载后的配置与原提交逐项一致，比较哈希相同。关卡快照、推荐战力、技能等级成长和存档结构未改。

## 对位实测

本轮使用完整技能模拟器执行技能，不再解析技能表估算系数。三个裸装阶段各取 80 名攻击面板英雄，对位同阶段攻击型或坦克型的中位主属性靶子；装备、培养及四属性为零。毕业对位读取本机 `maxhero` 的第 0 套预设，数据库以只读方式打开，没有改存档。

普通技能试验关闭受测英雄的普攻与队长技，保留正常技能冷却、延迟结算、DOT、被动和召唤物行动；靶子不主动反击，但持续伤害照常结算。双方去除属性克制优势，靶子不带自身技能、天赋或复活机制。每个对位 60 个种子，最多 180 回合，统计实际施放的普通技能次数。队长技另开试验，只允许释放一次，再结算延迟效果，观察至第 10 回合。

因此，这张表表示“普通技能及其衍生效果独立击杀中性目标”的次数，不代表完整双向战斗的回合数。依赖普攻等机制而未能击杀的对位单独记录，不混入有限次数的中位数。

**中期落入目标，前期偏慢，裸装满级偏快。** 不改变技能等级成长时，单一全局倍率不能同时把这三段全部压进同一区间。该结果也不能拿来修改已确认的普通前五章敌人数值。

## 英雄独立强度复测

沿用既有独立受测流程：每名英雄、每个适用环境各 100 场，只给指定受测英雄计数；左右各 50 场、五个位置各 20 场，同场十名英雄互不重复，队友集合和敌方集合不重复。新旧模型使用完全相同的阵容与种子。每个模型 26,400 场，合计 52,800 场。

当前目录为 132 名：普通 97、皮肤 35。没有沿用旧报告的 129 人数量。培养口径保持既有复测的 125 级、普通技能10级，其余培养清零；紫卡专属英雄保留原流程的橙卡面板归一口径。

伤害通道与变化方向可以对应上，但以下属于机制解释，不是逐项移除因素后的因果实验：

| 英雄/类型 | 证据与解释 |
| --- | --- |
| 奥能行者，大系数单段与吸血 | 普通技能是单段魔法，受全局倍率和比例减伤压低；队长技则是原生类型3吸血，真伤比例提高能抵消部分削弱，不能把两个通道都解释为同样变弱。普通榜整体伤害占比由32.3%降至26.9%，还需结合出手与续航交互复核 |
| 伊芙琳，多段、破甲、斩杀续接 | 普通技能有两段较小伤害和破甲，低系数段不再被减法防御压到下限；其收割机制仍保留 |
| 吉格斯，低系数多段与显式真伤 | 普通技能两段小系数，队长技为预除比例的 `true_damage`；两种伤害通道相对大系数普通伤害受益，伤害占比由24.6%增至29.6% |
| 加百列，原生类型3真伤 | 普通技能五段均为 `damage` 类型3，直接受0.3→0.5影响；初始真伤比例与0.66相乘的净系数仍高于旧值，伤害占比由17.8%增至23.7% |
| 索拉卡，治疗 | 治疗没有乘0.66，而对手伤害下降；长战斗中续航的相对价值提高 |
| 维嘉等手写技能 | 已实际执行；其排名与伤害占比下降，但不能仅凭“单段/多段”标签推断每个分支的最终强度，需定点复核 |

平均战斗从 10.29 回合延长至 14.72 回合；触及40回合上限的场次从899/26,400增至1,885/26,400。后续校准还需要同时约束拖长战斗与治疗收益，不能只看每次技能伤害。

## 参数建议与下一步停点

p=1.5、c=0.7和90%上限保持已确认值。真实伤害比例0.5、显式真伤修正0.8、全局倍率0.66仍仅保留为研究初值，**不建议把它们批准为最终发布参数**。0.85、1.05的毕业试验也没有解决个体差距。

建议先对超标队长技、单体与范围输出、原生与显式真伤分别列出需要调整的英雄，再经确认后改个体技能端点并复测，保持既定等级成长曲线。瑞雯队长技应优先复核；冰鸟需要连同范围与持续控制价值评估，不能只根据单体靶场增加系数。治疗英雄的排名与战斗时长也应一并复核。

当前停在阶段2的报告确认处。收到明确确认前，不改个体技能、不生成敌人四属性、不改客户端或默认公式。精英前五章是否豁免的问题留到阶段3开始前确认。
