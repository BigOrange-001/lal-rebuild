# 新旧伤害公式切换

2026-11-13，按用户要求采用现有比例公式作为默认。参数沿用 `combat-rules-1.0.4.json`：防御曲线 p=1.5、c=0.7，减伤上限90%，原生真伤比例0.5，显式真伤技能修正0.8，全局伤害倍率0.66；闪避和暴击使用已有的新斜率与上限，暴伤固定2倍，韧性通用减伤取消。

游戏设置新增“使用旧版伤害公式”。默认不勾选，勾选后切回旧版，取消后恢复新版。选择保存在本机，与“显示战斗生命值”和音乐音效独立。从下一场战斗生效，当前战斗的模型不因切换设置而改变。双方及所有战斗模式共用同一个模型。

客户端从完整配置读取 `combat_rules`，配置缺少该字段时使用同规格的内置参数。新版参数作用于战斗使用的数组副本，原 `system_simple.attack` 保留；旧版直接使用原数组参数。物理/魔法防御、原生真伤、预除真伤比例的技能、暴击、闪避以及伤害结算中的全局倍率和韧性同步切换。治疗和护盾不乘全局伤害倍率。

本次不改变英雄面板、技能系数、关卡敌人面板或推荐战力。此前校准结果仍为历史结果，本次没有重跑大规模平衡校准。新旧对比脚本显式构造旧版副本，避免默认值变化后把新版结果误标成旧版。

检查包括客户端实际方法与Python新旧模型的216组伤害对照、暴击与闪避边界、本机偏好保存、跨战斗切换及原数组保持不变；同时复核既有新公式边界和血条联动。客户端已在可玩基线上增量编译，并随全卡测试端打包安装；未从原始模板重跑全部178阶段，也未代替用户进行游戏内实战验收。
