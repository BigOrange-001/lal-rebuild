# 新旧伤害公式切换

## 1.0.5 新版四属性

默认比例模型和设置中的旧版开关仍按每场战斗锁定。新版使用天赋、装备和战斗增减益生效后的数值。令 `d = 攻方暴击 − 守方韧性`，`G(x) = ln(1 + max(0,x)/10000) / ln(11)`。

| 项目 | 新版结算 |
| --- | --- |
| 暴击伤害 | 基础 200%，暴击时伤害倍率为 `2 × (1 + 0.6G(d))` |
| 额外韧性减伤 | 承伤除以 `1 + 0.6G(−d)`。直接伤害与持续伤害均在护盾吸收前结算；附加伤害沿用原基数，不再结算一次 |
| 真实伤害 | 技能真伤、原生真伤与固定数值真伤（如卡莎电浆、护士阿卡丽被动）统一：真实伤害按面板100%计算，不扣物防／魔防，之后照常经过韧性、减伤、护盾和保命结算 |
| 附加伤害 | 按一次已结算伤害的比例追加的伤害（黑夜亚索暴击追加、安妮引爆灼烧、深渊遗物反伤），基数已经过完整结算，不再经过防御与韧性，以白色数字显示 |
| 闪避 | 设 `x = max(0, 守方闪避 − 攻方精准)`，闪避率为 `1 − (1 + x/4000)^(−ln(5)/ln(26))`。过剩 4000 点约为 29%，过剩 10 万点为 80%。精准追平后必中 |
| 治疗与护盾 | 施放者自身精准使治疗与护盾量乘 `1 + 0.5G(精准)`。10 万精准提升 50%。按已扣生命值固定结算的亚索与遗物吸血保留独立规则 |

命中后进行暴击判定。当 `d ≤ 0` 时，概率为 `0.15 × (1 − d/10000)^(−ln(3)/ln(11))`；当 `d ≥ 20000` 时，为 `0.60 − 0.45/(1 + 1.2G(d))`。两段之间用五次多项式连接，在两个接点同时匹配函数值、一阶和二阶导数。新版判定精度为 0.01 个百分点，每次判定使用一次原战斗随机数。

## 2026-11-13 版本记录

2026-11-13，按用户要求采用现有比例公式作为默认。参数沿用 `combat-rules-1.0.4.json`：防御曲线 p=1.5、c=0.7，减伤上限90%，原生真伤比例0.5，显式真伤技能修正0.8，全局伤害倍率0.66；闪避和暴击使用已有的新斜率与上限，暴伤固定2倍，韧性通用减伤取消。

游戏设置新增“使用旧版伤害公式”。默认不勾选，勾选后切回旧版，取消后恢复新版。选择保存在本机，与“显示战斗生命值”和音乐音效独立。从下一场战斗生效，当前战斗的模型不因切换设置而改变。双方及所有战斗模式共用同一个模型。

客户端从完整配置读取 `combat_rules`，配置缺少该字段时使用同规格的内置参数。新版参数作用于战斗使用的数组副本，原 `system_simple.attack` 保留；旧版直接使用原数组参数。物理/魔法防御、原生真伤、预除真伤比例的技能、暴击、闪避以及伤害结算中的全局倍率和韧性同步切换。治疗和护盾不乘全局伤害倍率。

本次不改变英雄面板、技能系数、关卡敌人面板或推荐战力。此前校准结果仍为历史结果，本次没有重跑大规模平衡校准。新旧对比脚本显式构造旧版副本，避免默认值变化后把新版结果误标成旧版。

检查包括客户端实际方法与Python新旧模型的216组伤害对照、暴击与闪避边界、本机偏好保存、跨战斗切换及原数组保持不变；同时复核既有新公式边界和血条联动。客户端已在可玩基线上增量编译，并随全卡测试端打包安装；未从原始模板重跑全部178阶段，也未代替用户进行游戏内实战验收。
