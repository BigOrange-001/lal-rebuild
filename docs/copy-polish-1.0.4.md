# 1.0.4 文案润色对照表

## 规则

技能说明在客户端最终显示层统一处理（`SkillSet.polishInfo104`），天赋、羁绊机制文本在服务端同规则处理（`server/copy_polish_104.py`），两边规则一致。只改文字，不改数值和机制。

- 术语统一：本分路/当前分路 → 本路；面板物理/魔法伤害、攻击物伤/攻击魔伤 → 物理/魔法伤害；X%攻击护盾/生命 → 相当于X%攻击力的护盾/生命；X码 → X距离。
- 去掉引擎细节：一次释放内完成、阵亡目标跳过不补选、合法目标、释放距离、"普通技能：/队长技能："前缀、重复行。
- 装备加成：装备·技能·部位：《技能》：仅…提高X% → 【装备】…提高X%；装备·名称：… → 【装备·名称】…。
- 数字：40.0% → 40%；空格分句改为逗号；句末统一句号。
