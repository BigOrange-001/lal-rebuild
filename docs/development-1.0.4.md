# lal-rebuild 1.0.4 开发验收记录

本次实现位于正式源码目录 publish/lal。本次按 PR 审查流程提交，保留主分支既有 Mod 接口、并行表现及 1.0.3 战斗修复；未部署或替换已有一键端。

2026-10-27 补充：21 位普通英雄橙卡形态及已确认美术接入，原英雄羁绊完整继承，新增 42 条装备羁绊；实现及验证范围见 [橙卡进阶实装表](orange-ascension-1.0.4.md)。本轮生成独立 Windows 试玩包，不替换旧一键端或已有存档，也未提交新的 PR。

## 战力和推荐战力

- 客户端与服务端的加权面板指数统一为 1.5。
- 生命、攻击、防御和队伍次级属性天赋由实际面板计入，不再额外叠加品质战力。恢复按 25% 有效覆盖率估值；破甲按 25% 有效防御覆盖率与减防率换算。该系数属于平衡设计，不是实测胜率。
- 装备、德诺、羁绊、天赋及技能变体按开战快照计算；保留原生两阶段取整。
- 主线第 1–10 大关按新旧同一敌方阵容战力比例全额缩放；11–25 大关线性减弱，26 大关起不缩放。此处以“第 26 大关开始完全不缩放”为明确终点。
- 灵魂塔第 1–79 层全额缩放，80–150 层线性减弱，151 层起不缩放。不修改敌人面板。

## 修复

- 仅 PVE 副本保留 40 回合限制和回合上限显示，其他模式没有固定回合上限，也不添加“无限回合”提示。
- 粉尘、天赋石、附魔书高阶资源本保留本阶掉落并增加所有较低阶素材；低阶数量随关卡阶数增加。
- 排名超过 100 时，对手池固定包含 91–100 的十名对手，缓存长度同时更新。
- 德诺仅已开启的全属性格子补齐上阵英雄羁绊；德诺成员自己不接受本阵容羁绊加成。
- 列表行改用背包记录副本，防止临时筛选/售卖保护写回永久锁。预设阵容保护及手动锁继续生效。
- 已强化英雄可作同名同品质升阶素材；仍须未升阶、未变形、未锁定、未占用。服务端既有规则允许强化，本次修复误锁路径并增加回归。

完整成员、属性、技能和组合规则见 [羁绊效果表](bonds-1.0.4.md)。三人组增加一个角色的机制；四/五人组重做一个角色的小技能与大招，其余成员获得面板或技能数值强化。保持技能强化等级；好友队长使用原阵容的强化快照。

## 英雄技能输出统一调整

新增最终输出层，放在全部英雄与羁绊技能生成之后执行。英雄（含皮肤、解说）的普通技能、大招与伤害型被动，其伤害、护盾、治疗系数及对应等级成长统一乘 0.8；增减益幅度、持续时间、目标数、冷却、位移及召唤物继承面板不变。原始普通攻击面板不变。

1821 条英雄技能记录已纳入本次规则，其中 28 条与非英雄单位或装备共享的技能建立英雄专用副本，避免连带改变野怪、小兵及装备技能。手写技能与皮肤技能由客户端输出函数处理，覆盖延迟伤害、受击反击、被动追加伤害、猫女回复、护士治疗和灰盾；中毒的生命上限伤害同步为原来的 80%，中毒易伤和灼伤减疗比例不变。

伤害转治疗等转换系数也属于本次治疗数据调整；由于输入伤害本身也降低，连续转换后的最终治疗量可能低于原来的 80%。技能增益系数及羁绊的面板加成未削减。

验证包含逐条技能及 1/10 级成长差分、增减益字段不变、重复加载幂等、非英雄/装备隔离、客户端实际输出函数、皮肤与持续伤害回归。已重新编译 Buff 和最终 Avatar 类并核验 SWF 内包含新输出逻辑及羁绊引擎。此次必须配套更新服务端与候选 SWF；尚未进行完整 AIR/安卓实机试玩。
