# 1.0.3 持续伤害规则

全部DOT忽略物防、魔防，施加时保存完整倍率，结算时不再乘额外0.3倍率。目标自身行动开始时逐次结算；火焰之书和符印保留原有原始伤害数值、品质等级曲线和持续回合。

- 普通中毒每次为施加时攻击对应毒值，加目标生命上限5%。统一描述文本。
- 有任意一种中毒时，受到伤害提高20%；多种中毒不重复叠加该易伤，最后一跳仍有易伤。
- 有任意一种灼伤时，受到治疗降低40%，即保留60%；多层灼伤不叠加减疗。
- 流血和玛尔扎哈幻象对护盾造成3倍消耗。例：基础伤害100、护盾150，消耗150盾后余下50基础伤害扣血；护盾400则剩100盾，不扣血。与技能书破盾倍率相乘，并按合成倍率折回溢出伤害。
- 清除减益、神佑复活会清除独立DOT记录；净化阻止新的可净化DOT。

技能DOT攻击倍率预算约为同目标完整直伤的3倍。锁定多段按完整直伤序列、弹射按单跳直伤计算；纯DOT参照同档直伤。此预算指基础攻击系数总量；中毒生命上限项、易伤、减疗和破盾属于额外机制，实际对局总伤害不会固定为3倍。不同来源维持原有叠加/刷新规则，未延长回合或额外增加重复结算。

英雄技能、手写技能、弹射灼烧和独立幻象在客户端与模拟器使用相同结算原则。技能书（含火焰符印）按用户明确例外保留原有伤害数值，仍统一适用穿甲、易伤和减疗规则。

`A_1139`现有品质版本统一改名卡尔玛。

先前导出的1000场英雄复测结果早于此次DOT规则调整；本次没有重新跑整套排名，旧胜率和Δ胜率不代表此次规则下的结果。
