# 装备羁绊绑定调整（2026-11-17）

覆盖全部99件紫/橙基础装备（不含技能书、低品质装备和升星衍生物）；每件1–3名英雄。
用户标定的21项全部保留。原专属效果保留；其余仅迁移装备归属，原技能强化部位、系数、成长不变。
部分专属装备也给其他合适英雄提供普通羁绊，但不会给新英雄复制原主人的专属机制。
黑夜亚索的攻击20%羁绊从源计划战刃迁到破晓长剑；卡莎的生命20%羁绊从影刃战靴迁到虚空战甲。

## 新年安妮与烈焰核心

新年安妮自带“不讲道理”（准备0、冷却1）：受到异常时净化全体友方，并对敌方全体施加破甲、虚弱、中毒和沉默。本人穿戴烈焰核心后，额外附加眩晕1回合；其余效果与冷却不变。原提伯斯伙伴机制与说明迁至普通主动技能。

无羁绊时：全体敌人受到33%破甲和33%虚弱2回合、中毒2回合（每回合50%攻击真实伤害，可叠加）、沉默1回合；净化全体友方并使其免疫有害状态1回合。烈焰核心羁绊额外增加眩晕1回合。两种版本均跨路生效，准备0、冷却1。

提伯斯成长、指令攻击和受主动伤害时的护盾，都归入普通主动技能，保留原数值和触发时机，不随普通技等级额外放大。
