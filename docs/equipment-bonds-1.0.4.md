# 1.0.4 装备羁绊：按英雄技能部位强化

覆盖 103 位橙卡英雄、206 条普通装备羁绊；35 件专属装备继续另算。普通、皮肤、同人英雄分别按当前实际技能设计。解说、野怪、小兵、未具名模板及非橙卡不参与。

## 强度口径

单件紫装的目标是让所绑定的整项技能提升约 12%，普通橙装约 8%。全部预算集中于指定部位，其他效果不变；不是把该部位只提高 12%/8%，也不是整位英雄的总伤害提高 12%/8%。

线性效果：局部增幅 = 整项技能预算 ÷ 该部分的等效收益占比。例：希维尔回旋刃返程占两段伤害的 3/7，紫装局部增幅为 12% ÷ (3/7) = 28%；超级伊泽瑞尔五连弹末段占 1/5，局部增幅为 60%。

召唤继承同时改变多个面板，采用现有战力指数 1.5 作为等效收益曲线：局部增幅 = (1 + 预算/占比)^(1/1.5) - 1。该估值不会修改召唤数量、寿命或递归保护。

## 估值场景与边界

- 纯伤害序列按约定目标正常命中、各段完整结算计算。希维尔按两段命中同一批目标；五连弹按五段命中；厄运小姐普通弹射按两个目标且首击未击杀计算。
- 伤害与护盾、治疗、增益、位移并存时，占比为逐技能填写的设计估值。基准为护盾被消耗、治疗不溢出、增益在持续期内有效、召唤物正常存活并输出；它们不是对所有战斗场景的实测提升保证。
- 标记、孤立、血线、叠层等强化只在原条件满足时产生收益；生命比例伤害保留原有上限，已触顶时不会继续增长。
- 先按部位修改系数及对应成长，再应用原有全局 80% 输出规则。增减益不受全局 80% 缩放。九英雄包的 2/3 前置缩放不变。说明中的局部增幅是相对增幅，不再次乘 80%。
- 两件装备分别绑定不同结算部位。普通羁绊不新增通用补伤、自疗、护盾，不覆盖全部技能输出；专属装备保留额外机制。
- 对 23 个受影响的“装备—羁绊重做技能”组合另行指定部位和占比，见后表。未知未来重做不会自动套到无关效果；现有全部英雄羁绊版本已验证有对应目标。
- 只认本人实际穿戴，重复装备不叠加；穿脱、好友助战快照及平时/战斗战力沿用同一技能映射。被动技能也可成为明确的强化对象。
