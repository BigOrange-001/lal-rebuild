# 探险排查与修复（2026-10-29）

| 问题 | 修复 |
| --- | --- |
| 满15人的名单会跳过选人页 | 手动进入总是打开最多15人的名单确认；战斗结束自动返回仍直接回地图 |
| 确认新名单后，布阵临时数据仍引用旧名单 | 同步更新临时名单与探险状态；忽略过期回包 |
| 敌方预览把战斗配置的培养字段当作生命值 | 预览与实战共用敌人快照构造，提供有效当前/最大生命与完整属性 |
| 后期四人敌队只显示前三人 | 四个位置全部展示并缩放至预览区域内 |
| 免费刷新为0后无法使用付费次数 | 分开判断免费次数和付费上限，确认框显示实际价格；待领奖时禁止刷新 |
| 重复点击、关闭面板后的迟到回包导致重复请求或跳页 | 地图请求互斥，错误后恢复；关闭及过期回包作废 |
| 同名英雄结算换序会串写生命 | 客户端提交实例编号，服务端按实例编号匹配；兼容旧客户端原顺序结果 |
| 生命上限变化后，剩余生命比例错误 | 进入战斗前按新上限同比换算，不改变当前地图冻结难度 |
| 无效阵型会静默替换成名单前三人 | 校验阵型，允许原版空槽但拒绝空队、非名单英雄、重复英雄和无效坐标 |
| 战斗进行中可以替换名单、购买加成或复活 | 拒绝这些操作，避免正在结算的生命记录丢失或付费被覆盖 |
| 非有限生命值会使结算抛出未处理异常 | 在消耗战斗记录前拒绝NaN/Infinity；缺少生命记录时保留战斗供重试 |
