普通邪恶小法维嘉 `A_1027` 的队长技能在本次伤害释放期间临时获得30000精准，正常结束或异常退出均还原。该固定精准不随本轮技能数值平衡倍率缩放，不影响圣诞老人维嘉 `A_1217`。

## 超级赛亚人孙悟空

- 普通「超赛变身」：仅作用自身，净化与神佑2回合，精准、闪避、韧性提升2回合，并治疗自己。
- 队长「真·龟派气功」：伤害并击退当前分路全部敌人，不影响其他分路。
- 被动「绝境逢生」：沿用原生负面触发路径，自身行动前持有负面状态时释放；作用于全队所有分路，包括自身。
  先净化全队，再生成施放者当前攻击力300%的盾，再添加50%力量、150%双防和神佑，均为1回合。
  盾先于本次力量增益计算，避免将300%额外放大为450%。

用户未指定的参数采用以下开发默认值，均在 `server/hero_skills_103.py` 可直接调整：

| 项目 | 默认值 |
| --- | --- |
| 普通技能准备/冷却 | 0/0 |
| 精准、闪避、韧性提升 | 各4500点（1级）至9000点（10级），线性增长 |
| 自我治疗 | 仅按自身最大生命值计算，1级12%至10级18%，线性增长；不附加攻击或精准，治疗效率与减疗仍正常结算 |
| 队长技能准备/冷却 | 0/0 |
| 队长技能伤害/击退 | 50%攻击魔法伤害、1500码，受地图边界和合法站位限制 |
| 被动准备/冷却 | 0/0，只在自身行动前持有负面时触发 |
| 被动盾、力量、双防持续 | 1回合，与净化、神佑一致 |

固定被动百分比在紫卡、橙卡保持一致，不擅自按品质缩放。

## 莫德凯撒

同时调整 `A_1137_5`、`A_1137_6` 使用的专属技能：

- 普通「毁灭一击」：锁定当前分路最近目标，先驱散增益、诅咒1回合，再净化自身1回合，提高精准、暴击1回合，最后对原目标造成魔法伤害。
  准备1、冷却3。最新要求将伤害、精准和暴击翻倍：当前生效伤害1级327.6%、10级655.2%，精准和暴击各6300至12600点，均包含原有5%平衡加成；持续1回合。
- 队长「不动如山」：全队净化2回合、100%双防、神佑2回合、21%力量，护盾为施放者当前攻击525%、持续2回合。100%双防为用户指定最终值，在通用平衡之后固定覆盖。
  保留准备3、冷却3；先净化，再计算盾，再添加力量，确保诅咒不会吞掉后续增益。
- 被动「悲伤收割」保持击杀触发、原范围和原回合数。只把数值幅度乘5：
  治疗系数0.15→0.75，三个真实伤害动作系数均0.24→1.2，虚弱内部数值0.05→0.25。
  原生真实伤害倍率和虚弱换算仍然适用，内部系数不等于最终面板伤害/减攻百分比。

通用T级平衡还会为莫德凯撒的治疗、伤害和虚弱数值增加5%：当前被动治疗系数78.75%，三段真伤动作系数各126%，虚弱内部系数26.25%。旧真伤通道仍乘0.3，故未计克制、暴击与终伤时基础为每段37.8%攻击、三段合计113.4%；虚弱使用内部除数，不能直接视为减少26.25%攻击。被动治疗仍使用旧攻击与生命混合治疗通道。

覆盖层在旧平衡、队长时序和装备技能之后应用；重复启动使用固定配置，不会再次乘5。最终投影步骤将莫德大招双防固定为100%，并由生效动作重建等级1说明，避免说明中的平坦数值与通用平衡后的数值不一致。

## 神佑共存与消耗

新技能使用显式 `timed_bless` 动作，原生 `bless` 保留永久复活语义。
限时神佑仍使用同一神佑状态及复活实现；`Buff.value>0` 标记限时，0表示旧版永久。

- 永久覆盖限时；限时不覆盖永久。
- 两个限时保留较长剩余时间，不相加。
- 只有一份神佑，不叠加复活次数；触发复活即消耗并按原生规则清除负面、恢复生命。
- 限时到期失效，永久不会因回合流逝而失效。
- 回合窗口沿用原生倒计时：在佩戴者行动前递减，变为负数移除。因此2回合神佑经过两次本人行动仍有效，第三次行动前失效。
- 神佑可以按原规则被驱散；诅咒等限制仍按原生增益规则处理。
