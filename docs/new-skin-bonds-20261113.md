# 黑夜亚索与神龙卡莎羁绊

沿用现有同品质皮肤羁绊规则：相关六星英雄上阵或放入已解锁的全局命运位才能激活；仅拥有、重复放同一英雄、普通形态或低品质替代都不能补齐成员。战斗采用服务端生成的羁绊快照，战中成员阵亡不改变本场的激活结果。装备羁绊只认本人所处位置的装备，同一件装备的重复实例不重复加成。

| 名称 | 成员 | 效果 |
| --- | --- | --- |
| 龙影夜刃 | 神龙尊者卡莎、黑夜使者亚索 | 卡莎 Q 每发命中后额外施加33%破甲，持续1回合；亚索被动暴击追加真伤从35%提高到50%。 |
| 异界剑盟 | 黑夜使者亚索、源计划亚索、兔女郎瑞雯 | 黑夜亚索大招伤害提升12%（按1.12倍结算），并且可以在沉默中释放队长大招，仍遵守队长、冷却、目标和眩晕限制；其他两位各提高20%攻击、20%生命。 |
| 猎心龙舞 | 神龙尊者卡莎、觅心猎手薇恩 | 两位各提高14%攻击、14%生命。 |

卡莎破甲在本发伤害结算后施加，后续弹体可享受防御降低；未命中不施加，分身继承本体的羁绊快照。33%按原生百分比破甲换算为实际物防、魔防剩余67%，不叠成更高比例。净化、抵抗、更强破甲与计时沿用原规则。

| 英雄 | 装备 | 数值效果 |
| --- | --- | --- |
| 黑夜使者亚索 | 源计划战刃 `E_1019_6` | 攻击提高20% |
| 黑夜使者亚索 | 暗影羽翼 `E_3007_6` | 生命提高20% |
| 神龙尊者卡莎 | 圣光双枪 `E_1020_6` | 攻击提高20% |
| 神龙尊者卡莎 | 影刃战靴 `E_5006_6` | 生命提高20% |

装备数值在英雄羁绊之后应用，预览与服务端战斗快照同序计算，不改技能系数或额外添加技能效果。脱下对应装备后加成立即失效；已包含羁绊的战斗快照不会在客户端再乘一次。

配置维护于 `config/reconstruction/new-skin-bonds-1.0.4.json`，在两位新增皮肤注册后接入现有英雄、装备羁绊表。客户端维护文件 `client/src/new_skin_bonds_104.aspart` 与同步脚本 `scripts/sync_new_skin_bonds_104.py`。原有亚索、卡莎同步后，再运行该脚本可重建钩子及源文件哈希。
