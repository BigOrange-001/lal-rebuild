# 深渊遗物战斗规格 v1

本规格对应服务端 `abyss_equip_passives.py`、`battle_engine.py`、`manual_ability_sim.py`。客户端需在 Avatar.as 实现同样通道；服务端离线模型不是原生客户端，不能凭服务端通过声称双端一致。

## 数据与共同约定

普通英雄事件被动继续占 skillB；新的 `equip_passives` 数组独立读取B类主词条，不写 skillB。A类只在 `skill.abyss_relic_A` 中读取。对象字段与完整20种文字由 sys.get_config.cfg.system_simple.abyss_relic_types 提供。
当前每个阵位只有1件深渊遗物，数组为扩展留接口，不允许前端自加效果。太古按服务端给出的 value 执行，阈值、持续回合和次数不乘1.25；#3、#12、#19有明确特例。
深渊快照没有这些字段，并标记 abyss_standardized=true；即使字段误传入，通道也忽略它们。

同路均指 line 相同，不限制距离；存活 hp>0，“友军”不含自己，含召唤物。第一位为队长，其他人不释放大招。
整数结算采用 Tools.toInt 语义：先保留5位小数再向零截断。伤害、治疗与护盾不允许因为二进制浮点误差把115算成114。
持续回合使用原生持有者回合的倒计时。第1回合为全局 round_index=0。

## 执行顺序

1. 完成原生单位初始化与快照面板，保留原skillB；每场仅一次执行装备初始化。
2. 队长光环先写入全队；随后入场护盾、大招准备。光环在本场队长死亡后仍保留，召唤物继承所在队伍的坚城减伤，统御通过继承面板进入召唤物，避免重复放大。
3. 直接伤害正常进行命中、属性克制、防御、暴击和全局倍率；#20在防御前拆分普通/真实部分，只做一次命中、暴击随机判定，然后合并。
4. 既有伤害修正后，装备依次处理：先声夺人→同心→A类高/低血线→坚城独立减伤→盾吸收→生命。
5. 护盾伤害先乘碎盾倍率；打穿后按倍率换回原伤害预算，溢出正常作用生命。
6. 致死保护先按原有祝福、泰达米尔不死顺序，再尝试复苏之羽。装备复活成功则这次不发真正死亡/击杀事件。
7. 受击后坚守回血/护盾→攻击者嗜血→受击者荆棘反弹→A类附加状态。损失统计在坚守恢复前固定，不因为回血抹掉本次受伤。
8. 然后沿用原生英雄事件被动：damage_taken、damage_dealt、hit、shield_break、kill、death。单个原生事件内部先完成现有英雄/Mod事件，再进入装备事件监听；疾风步监听 dodge。
9. 装备反弹和嗜血有来源标记，反弹不得再次触发反弹；嗜血不得触发护士受治疗反击。原有Mod链深度/次数保护保持。

## B类词条逐项

| # | 时机、次数与公式 |
| --- | --- |
| 1 | initialize，护盾=int(hp_max×1/1.25)，3回合；每场1次。使用现有护盾合并规则，不额外相加同类盾。 |
| 2 | round_index==0，所有自身伤害×2/2.25，含DOT与反弹，之后不再生效。 |
| 3 | 每场首次受伤后0<hp<hp_max×0.5，直接恢复为hp_max；此为设定生命的恢复，不吃减疗或治疗增幅。hp==50%不触发，已阵亡不触发；太古额外hp_max×0.25护盾3回合。 |
| 4 | 原有致死保护未救活时，每场首次以hp_max×0.5/0.625复活，至少1生命；清除负面状态及原生/手写/遗物DOT；下次死亡不再触发。 |
| 5 | 敌方直接攻击造成实际伤害后，反弹其实际生命损失+实际盾消耗的20%/25%；不含过量伤害，DOT不反弹。反弹是附加伤害（白色数字），基数已完整结算，不再经过防御与韧性，但吃装备全伤害修正/盾。来源 relic_reflect，禁止反射反射。致死攻击也可以反弹。 |
| 6 | 成功闪避后，hp_max×10%/12.5%盾，按全局回合最多2次。设计未指定盾时长，采用现有默认2回合；多次沿用原生护盾取较强/刷新规则，不相加。 |
| 7 | 对方实际生命损失+实际盾消耗×25%/31.25%转治疗，伤害统计含DOT、所有技能及自身反弹，不含过量。按正常治疗结算，可被圣佑/减疗修正，溢出不增加生命。来源 relic_lifesteal；护士阿卡丽 _on_healing_received 必须跳过该来源；其他普通治疗仍可反击。 |
| 12 | 对盾普通2倍、太古2.5倍，与技能书盾伤乘区相乘。例：100伤害打150盾，普通消耗75预算打完盾，余25打生命；太古消耗60预算，余40打生命。盾消费换回预算向上取整。 |
| 14 | 穿戴者施加的全部治疗和护盾×1.5/1.625；只放大一次，在普通治疗上限/减疗前、护盾合并前结算。技能书和原有技能强化仍保留。遗物触发护盾不继承当前攻击的技能效果倍率；穿戴者适用的护盾增幅仍保留。 |
| 15 | 仅入场队长激活，全队伤害×0.94/0.925；与原有减伤相乘，非加法，不改防御。 |
| 16 | 仅入场队长激活，全队攻击面板×1.06/1.075；一场只应用一次。 |
| 17 | 每次自身伤害读取同路当前存活友军数量n，伤害×(1+n×0.15/0.1875)；队友阵亡/召唤/转路立即影响后续结算。 |
| 18 | 原有召唤快照的8项面板先×1.35/1.4375，再按召唤技能各项继承比例/额外倍率结算。不让召唤物继承装备被动本体；不改变数量/寿命。 |
| 19 | 仅有大招且作为队长时，开场大招准备=max(0,原准备−2)，不改施放后的冷却。不生成太古。 |

治疗来源标记必须随同同步和延迟治疗传递，不能根据当前穿戴物推测；一件深渊遗物不妨碍英雄自己的受治疗被动。

## A类变体和命中归属

后端预生成普通/太古变体，保留既有动作、技能成长、英雄羁绊和装备羁绊。equipment_source_skill_104 保留机制身份。
前端需新增普通技能执行上下文（owner、slot、effect、已附加状态目标集合），所有原生和手写命中统一读取；大招、普攻、skillB和其他英雄代打不继承这个上下文。

| # | 执行 |
| --- | --- |
| 8/9 | 当前伤害落地前读取目标hp/hp_max，严格>0.5或<0.5时，普通小技能伤害×1.4/1.5 或×1.6/1.75；恰好50%不触发。 |
| 10/11 | 小技能成功对目标造成伤害（含打盾）后，每次施放对同一目标只附加1次遗物DOT；2跳，每跳当前攻击×0.4/0.5。同源同类刷新，不同穿戴者分别存在；不加原生毒的额外5%生命项，保留中毒易伤/灼烧减疗语义。每跳仍吃全局伤害倍率，最后一跳结算后才解除状态。净化清除。 |
| 13 | 每次小技能对每个已命中目标至多判定一次，随机整数[0,1000000)小于200000/250000即眩晕1回合；不会在每个多段伤害额外重掷。 |
| 20 | 物理/魔法原始伤害按0.4/0.5拆成真实部分，其余仍为原伤害类型；真实部分按真实伤害规则结算（新版公式为面板100%）。原本即是真伤的段不重复转换；两个部分共享命中与暴击。 |

服务端已传递普通技能延迟范围打击、炸弹、持续区域、蓄力释放的上下文，附加状态目标集合也随之传递；DOT tick 不重新触发寒霜或附加另一层遗物DOT。
不为仅治疗/护盾且没有敌方命中的技能强行增加一个敌方目标。

## 对照样例

[对照目录](roguelite-abyss-equip-passive-cases/)共27份：14类B各含普通/太古，时之沙仅普通。
每份含 input.team_a/team_b 原始快照、seed、combat_model、attack_overrides、commands，以及每个命令后的完整期望状态和累计 equipment_events、rng_calls。
样例以中性伤害参数隔离词条公式，不代表正式关卡。执行 initialize、damage（已完成防御/全局倍率的伤害）、heal、buff、dodge、round、hp（测试设置）、summon；客户端测试适配层按命令调用对应入口，并逐步比较expected。
导出：`python scripts/abyss_passive_cases.py`。服务端测试同时有独立手算断言，不只是快照自比。

必须另做真实战斗场景的双端逐事件验证；当前27份是交接基准，客户端尚未执行。
