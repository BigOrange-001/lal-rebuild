# 英雄技能等级成长检查（2026-10-30）

覆盖英雄原技能、英雄羁绊的所有组合变体、装备羁绊及其组合变体，共 3,610 个技能配置：普通技能 2,106 个、队长技 1,376 个、被动 128 个。包含目录内全部品质条目；强度测试中的解说卡排除规则不影响本次全目录检查。

统一公式：`等级 L 数值 = 1级数值 × (1 + (L - 1) / 9)`，等级限定 1～10。伤害、治疗、护盾、属性增减、吸血/转化比例、召唤面板等数值系数均按此规则。冷却、持续时间、范围、目标/连击/层数上限、触发条件和机制标记不作为数值系数成长。

普通技能以修改前的 10 级数值为端点，倒算 1 级及每级增量，保留刚完成的满级平衡，包括普通阿卡丽的加强。队长技和被动在现有客户端仍固定使用 1 级；保留该级当前实战强度，同时补齐配置中的 2～10 级线性曲线。本次没有增加队长技或被动的升级入口。

最终加载流程在英雄/装备羁绊变体及共同输出倍率生成后统一校正成长，避免后生成的技能覆盖成长。旧复合技能通过单一输出倍率成长，固定其内部原有缩放参数，避免同一伤害重复成长；追加的普通动作独立成长。延迟治疗、护盾、召唤、连锁持续伤害同步读取等级数值。此前写死的皮肤羁绊护盾、力量/闪避、减伤、寒冷减速、宠物成长等系数已转为配置参数。圣诞被动每层攻击增益也改为读取实际技能系数。

技能说明同步绑定对应系数。部分效果由被动提供，使用被动自己的当前等级，而不是施放它的普通技能等级。两倍关系针对技能系数；最终伤害、有效治疗和实际减伤还受双方属性、缺失生命、叠层、触发条件及机制上限影响。

验证结果：

- 13,076 条数值曲线、130,760 个逐级数值全部通过线性和端点检查。
- 执行客户端实际 `SkillSet.init` 和 `getNativeSetting` 方法，36,100 个技能/等级组合与服务端快照一致。
- 检查实际技能说明方法，原生/嵌套/复合参数均能解析；没有未解析的成长标记或 NaN。
- 普通复合技能施放检查覆盖当前仍在目录内的 20 种手写普通技能，确认输出仅成长一次；另外验证混合技能中的附加增益不重复乘复合倍率。
- 83 项针对性回归通过，包含 39 个原生皮肤战斗/状态场景，以及羁绊、装备、统计、说明和特效相关检查。
- Avatar、SkillSet 均通过 FFDec 实际编译，产物为 `build/skill-rank-verified-20261030.swf`。此产物仅供编译验证，未打包 APK、安装或重启运行中的服务；未执行新的英雄胜率复测。
