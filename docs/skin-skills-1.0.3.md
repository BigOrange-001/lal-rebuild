# 1.0.3 四名皮肤英雄技能

四组英雄现有紫、橙品质均应用本次设计。新技能在通用T级平衡和DOT配置之后单独应用，不再叠乘旧技能强化系数。护士阿卡丽在之前面板调整的基础上转换为双抗坦克；其他三组保留既有面板。不复用其他英雄的技能行，重复加载不会再次强化。

## 猫女卡特琳娜 A_1129

普攻伤害类型改为真实伤害。

小技能准备0、冷却2。1级获得5000精准，持续2回合；突进到本路最前敌人附近，遵守原生站位间距。锁定本路最靠前3名敌人，各造成60%攻击真实伤害，再对原主目标追加50%攻击真实伤害。恢复本次技能实际扣血总量的30%；不计过量伤害、护盾消耗、连锁被动伤害。1～10级四项收益线性翻倍：10000精准、120%群体伤害、100%主目标追加伤害、60%伤害恢复。持续时间和技能间隔不成长。原主目标死亡后追加段不转移目标。

队长技能准备2、冷却4。先清除自身负面，并获得2层负面抵消；保留至耗尽或被驱散。全图敌人各受到6段30%攻击真实伤害。每段独立命中和暴击，按本次大招实际暴击次数，在全部伤害结束后添加持续2回合的力量，数值为次数×3%。连锁被动的暴击不计入大招次数。

被动在造成最终击杀后触发：3次攻击分别从全图当前存活敌人中重新随机索敌，各造成40%攻击真实伤害，可重复选中同一存活目标。被动击杀会排队产生下一次触发；单个英雄每个全局回合最多触发5次，即最多15次被动攻击。每次触发先占用额度，再处理其3次攻击，因此连锁不会递归绕过上限。神佑、保命等生效后仍存活的不算击杀。被动倍率不随技能等级成长。

双重净化复用净化状态的数值字段储存剩余层数；普通净化仍使用原有回合与一次抵消机制。抵消常规减益、手写DOT和定身时仅耗1层；驱散增益会清除整个状态。普通净化不会覆盖尚未消耗的多层净化。

## 极地射手艾希 A_1202

普攻、小技能和被动追击为物理伤害；大招为魔法伤害。

小技能准备1、冷却0。1级自身获得100000暴击，持续1回合；对本路所有敌人造成70%攻击物理伤害，命中后施加35%破甲，持续1回合。1～10级线性成长到200000暴击、140%伤害、70%破甲。破甲按游戏既有双防削减规则换算，使用百分比对应的内部系数，避免把35%错写成只降低25.9%。

队长技能准备3、冷却3。本次施放期间精准临时加50000，结束或异常退出后恢复原值；独立于已有精准buff。主目标从全图敌人中按实时总攻击力选择，包含力量等即时加成，同值按原队列次序。攻击主目标及其同路300码内全部敌人，造成300%攻击魔法伤害，命中后附加1回合诅咒与1回合眩晕。临时精准不残留到普攻或后续技能。

被动n初始0。每个全局回合第一次进行普攻时，先令n加1，最多4，再对本路随机存活敌人追加一次60%×n攻击物理伤害。同回合多次普攻均可追击，但n只加一次；原普攻未命中仍算进行过普攻，追击独立判定命中。整回合未普攻则n减1，最低0，连续跳过回合时逐回合扣减。追击单独使用被动上下文，不会再次触发追击或普攻技能书效果。

## 邪恶圣诞老人维嘉 A_1217

小技能准备0、冷却0。对本路一名随机存活敌人造成魔法伤害，1级130%、10级260%，仅伤害随等级成长。造成伤害后获得1层固定5%永久攻击增益；同层相加，再与其他攻击增益相乘。例如4层增益与50%力量同时存在，攻击系数为 `1.20×1.50`。层数保留至战斗结束，普通驱散不清除。

队长技能准备0、冷却6。对全图所有敌人造成30%攻击真实伤害，命中后眩晕1回合。

每次最终击杀任意敌方单位（含召唤物）时，立即增加2层攻击增益，并将本局累计击杀数加1。每次释放小技能时，先锁定结算次数为 `1＋累计击杀数`，再逐次重新随机选择本路存活敌人并造成伤害、增加1层攻击增益。击杀本身不立即施放小技能。本次新增击杀从下次释放开始增加结算次数。没有本路目标或自身死亡时停止剩余结算，不空刷层数。

用户最终确认：初始每次技能结算1次，累计击杀1名后每次结算2次、累计击杀2名后每次结算3次；每次释放开始时锁定次数。每层5%不随技能等级提升，累计击杀与攻击层数均在新战斗中重置。

## 护士阿卡丽 A_1208

紫、橙两种品质改为双抗坦克（stat_profile=3），普攻为真实伤害。转换基于通用平衡后的面板：生命及成长乘1.2，攻击及成长乘0.5，物防和魔防均使用原双防平均值的1.5倍，成长同样转换。速度、射程、资源、培养与装备保留；转换只应用一次，前后数值记录于配置标记中。

小技能准备1、冷却2。先净化全图所有存活友军（含自身和召唤物），再以净化后自身实时总攻击力计算每名友军的治疗。1级70%、10级140%，线性成长，不附加旧治疗通道的10%最大生命或精准项。

大招准备3、冷却3。一次选定全图剩余生命比例最低的存活友军，比例相同时沿用队列顺序。对该目标和自身分别施加净化、永久神佑，并各治疗护士阿卡丽最大生命的50%。选中自身时保留两次独立施放：第一次治疗即使回满，第二次仍有完整治疗事件和被动伤害。50%不随技能等级成长；神佑不叠加复活次数，并遵守永久覆盖限时的规则。

被动只由护士自身受到的治疗触发，包含自身或其他单位施放的治疗。先应用施放者治疗效率、目标减疗，再区分实际恢复生命与过量治疗：每个全图存活敌人分别受到“实际恢复量×40%＋过量治疗量×100%”的固定真实伤害。两项比例均不随等级成长，不再乘攻击、精准、命中、暴击、护甲或旧真伤0.3系数；终伤、韧性、伤害易伤、护盾及保命仍按统一伤害结算。用被动攻击上下文处理，不触发普通攻击追击、吸血或主动技能反击。

普通治疗和原有按伤害回血的路径统一在最终生命入账时截断，以免提前丢失过量治疗。死亡单位不会被治疗复活，零治疗不触发被动。
