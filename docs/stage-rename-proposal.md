# 单机主线改名方案（30 章 / 135 关）

> 状态：已落地到 `server/player_copy_104.py`（`STAGE_TITLES_104` 覆盖全部 135 关，新增 `CHAPTER_TITLES_104`），测试见 `server/test_player_copy_104.py`。下文"现名"指改名前玩家看到的名字。
> "现名"的取法：用 `gateway.load_game_config` 完整加载 `config/reconstruction/full-config.json`，经过 `apply_player_copy_104`（`STAGE_TITLES_104` + `display_stage_name_104`）处理后取得。
> 敌人取自 `combat_main[ID]['team2']`，中文名查 `cfg.avatar`，只列英雄，不列小兵。头目关列在第一位的是头目本人。

## 整体设计

1. **一条路线走到底**：绿阶（1–5）是对线期，从泉水出发，经过兵线、草丛、一塔、河道；蓝阶（6–10）进入中期，经过中路河口、红蓝野区、视野盲区，到二塔；紫阶（11–15）争夺史诗资源，依次是峡谷先锋、炼狱龙坑、男爵巢穴、高地塔，最后推掉**水晶枢纽**，峡谷篇在这里收尾。橙阶前半（16–24）走出峡谷，游历符文之地的势力和其他地图：诺克萨斯、比尔吉沃特、祖安、皮城、双城、暗影岛、扭曲丛林、艾欧尼亚、嚎哭深渊。橙阶后半（25–30）的敌人全是皮肤英雄，主题是皮肤盛典：开幕、长廊、巡游、赛场、殿堂，终章**王者之巅**，呼应游戏名《最强王者》。
2. **地点尽量接住原场景**：章节新名对应原名的意象（冻河→冰封河道、断桥→中路河口、下沉水道→男爵巢穴、旧王城石阶→高地塔前、钟楼→皮城钟楼、码头→屠宰码头），所以 `campaign_scene` 的描述文字不改也基本说得通。
3. **普通关要贴合本关，同时要有风味、有变化**：同一章里混用几种写法，避免一个句式连着出现：① 英雄＋招牌动作或物件，写得有画面（布里茨钩人、圣诞维嘉送礼、护士查房）；② 英雄称号或描述性别称（法外狂徒、操控时间的老人、灯柱下的宗师）；③ 招牌技能名或势力、地名（魔影迷踪、黄昏之幕、不朽堡垒、德玛西亚双璧）；④ 对局里的情境说法（第一波兵线、推线进塔、突然的gank、趁乱偷大龙、兵临水晶）。过于平淡的"英雄名＋泛泛动词"（如"贾克斯拦路""格雷福斯开火"）已经换掉。仍然不写"五人组、残组、三点"这类数人头的说法，也不用运兵车、维修队、救护所这类写实军事词。
4. **头目关写成有故事的描述**：每章最后一关（表中 🏁）不直接用称号，而是用一句带情节的描述，从头目的背景、台词或招牌特征里取（图奇→隐匿的暗影、迦娜→风暴来袭、菲奥娜→无双挑战、千珏→生命与死亡、提莫→队长待命）。第15章是峡谷篇的高潮，接在"兵临水晶"之后叫"突破水晶"；终章五个敌人全是皮肤英雄，定为"全明星决战"。30 个头目不重复。
5. **格式约束**：关卡名 4–7 字（为了容下"操控时间的老人"这类别称，上限从 6 字放宽到 7 字），章节名统一 4 字；135 个关卡名互不重复；不出现"封锁/封口/封门/近卫/最后的"（已用脚本校验）。只改名字，不动关卡内容和数值。
