# 召唤物实时面板继承

所有召唤入口统一在创建当刻读取施法者完整属性，按技能中的对应倍率折算生命上限、攻击、双防、命中、闪避、暴击与韧性。此时装备、德诺阵、公会、培养、天赋、被动书已经在英雄面板中；临时增减益、永久/限时战斗叠层和队伍光环通过实时 getter 读取。

普通召唤不再用召唤物模板的基础/成长值代替继承属性。炮台、手动策略召唤、普通技能分身、英雄能力召唤及自定义英雄效果序列均调用同一继承函数。非等比技能保留各主属性单独倍率，队长额外召唤倍率仍只乘一次。

召唤结果是当刻快照，满血生成，生命与攻击下限为1，双防/副属性允许0。已继承的天赋与光环不会再次计入召唤物；之后直接施加到召唤物的增减益仍正常生效。主人后续属性变化不回写已经存在的召唤物，再次召唤读取新值。原有召唤数量、存活时间、技能和专用移动/射程保持各入口规则。

服务器同步使用同一规则，并保留召唤/分身策略与队长倍率。修复了永久战斗叠层读取时把小数截为0的问题。旧的“按自身基础成长计算”技能说明已更新。

1.0.3 开发源码和自定义英雄接口工作副本同步修改；两套 Avatar/SkillSet 均实际编译通过。自动检查覆盖11个客户端入口场景、实时增减益、不同主属性倍率、队伍光环、防止重复加成、零属性、无效倍率、满血生成及召唤后快照稳定性。检查产物位于 `build/summon-stats-103-check/`。尚未重新打包或安装游戏，未进行实机战斗验收。
