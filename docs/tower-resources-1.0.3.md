# 1.0.3 灵魂塔与资源挑战

开发改动由网关启动时应用，原始配置作为旧版输入保留；此记录不代表已安装或发布新包。

## 灵魂之塔

全塔180层，所有层均要求三路敌人全部消灭（原生 `win=[-2]`）。维持消耗10体力、逐层解锁、已解锁层可重复挑战。

| 敌人品质 | 单次胜利奖励 |
| --- | --- |
| 低于橙色 | 高级召唤对应品质卡池按权重抽1张整卡 |
| 橙色（含新增混合阵容） | `100+层数×2`个橙色英雄碎片 |

当前1～20层为蓝色、21～40层为紫色、41～180层采用橙色碎片奖励。橙色碎片先按VIP召唤橙池权重无放回选10名不同英雄，再各分配1个碎片；剩余碎片逐个均匀随机分配给这10名英雄。150层总计400个、180层460个。权重支持小数，采用与召唤相同的整数比例换算。移除原有固定120碎片、101层后额外橙色整卡奖励。

151～180层每次开战随机生成9名125级、技能10级、满进阶且突破极限的英雄。第一位队长保证为皮肤橙卡，其他8个位置独立按皮肤橙40%、普通橙30%、紫卡30%抽类别，类别内均匀选英雄，允许同英雄重复。队长属于额外约束，因此全体9个位置的皮肤橙占比不固定为40%。三路各3名。

敌人候选池只接受内置英雄和可用的自定义英雄，排除召唤衍生物、小兵、野怪和签到展示单位。Mod 的作用域别名先归并为原始英雄 ID，避免重复进入池子；`unitType=summon` 的鲸鱼等衍生单位不会被抽为塔敌人。

推荐战力从150层现有约100亿以等比方式增长，180层目标500亿。敌人实际四维按原生战力公式拟合；推荐值使用拟合后实际快照战力，整数取整带来微小目标误差。每场随机阵容与属性一起写入战斗记录，起始回执和结算共用同一份快照，不在结算时重新随机。

彩蛋改为188888金砖，全部180层三星（540星）且有逐层胜利记录后可领取一次。旧存档已领取的通关奖励继续保留领取标记，不重新发放。

## 资源挑战

英雄经验、L币、粉尘、印记、附魔书、培养书、天赋点、德诺石、技能饼干和远古试炼均按章共用次数；该章所有难度共用每天12次基础挑战机会，互不占用其他资源章的次数。

进入战斗与失败均不扣挑战次数；胜利结算时原子扣1次。失败仍消耗原有开战体力。每天每章可购买 `VIP等级+2` 次，每次50金砖增加1次挑战。VIP0可购买2次，VIP3可购买5次。购买可以在基础次数未耗尽时进行。

服务器按系统游戏时间的北京时间日期重置使用次数和购买次数。跨日战斗在胜利结算日扣次数。购买和结算均支持actionID重放；金币、奖励、背包、次数与战斗状态一并提交，背包不足会整笔回滚。在途多场战斗的胜利仍会重新核对剩余次数，不能并发超领。

原版活动关卡卡片新增“购买次数”按钮及确认框，显示所有难度共用的剩余次数；次数不足时点挑战也进入购买提示。购买后同章所有卡片同步刷新。战后重试和自动挑战入口使用相同的剩余次数计算。

## 远古试炼11～15档

保留1～10档原有敌人、战力、基础奖励和普通装备掉率。11～15档各使用不同的10名125级、技能10级、满进阶且突破极限的普通橙色英雄；每档队长不同，界面头像从该档实际队长读取。保留第10档的站位模板，拟合战力逐档等比增长，15档目标20亿。

| 档位 | 普通橙装掉落率 | 额外专属橙装掉落率 |
| --- | --- | --- |
| 10 | 25% | 0 |
| 11 | 30% | 0 |
| 12 | 35% | 0 |
| 13 | 40% | 0 |
| 14 | 45% | 0 |
| 15 | 45% | 5%（独立判定） |

普通装备池排除专属装备、技能书；15档额外池只包含配置标记的专属橙装。两次均成功时掉2件，两次均失败时不掉装备。额外专属发放只授权本次已验证的抽取结果，其他获取渠道不因此开放。

## 购买体力

每次购买增加当前自然体力上限对应的完整体力，可超出自然恢复上限。例如当前50、自然上限130，购买后为180。储存上限500；购买后恰好500允许购买，超过500则在扣费和增加购买次数之前整笔拒绝。原有每日购买额度、递增价格、日期重置和请求重放规则保留。
