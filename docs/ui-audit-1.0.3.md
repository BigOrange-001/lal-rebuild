# 1.0.3 界面遮挡排查与奇遇改版

本轮静态排查以当前源码链最终覆盖关系为准：从检查SWF导出370个UI类，再用 `client/build.json` 各类最后一条源码覆盖旧定义。清单保存在 `build/ui-audit-103/source-inventory.json`。包含27个screen、171个panel、146个element、9个map、10个stage、7个effect；115类有列表/滚动布局，12类引用原生文本或网页覆盖层。

重点复核登录/注册、首页公告、英雄背包/出售/上阵/预设、装备强化/附魔/技能书、天赋、奇遇与活动、PVE/PVP、德诺阵、公会、社交、邮件，以及通用弹窗和战斗HUD的坐标、层级、列表底部与交互生命周期。没有对无证据的问题做全局缩放或大改布局。

## 已修复

- 注册资金程度菜单由登录面板根层持有，打开时提升至所有兄弟控件之上；原生账号/密码输入框保持隐藏，关闭后恢复。加入遮罩点按关闭、短淡入和移除时动画清理，阻止迟到回调把原生输入框重新显示到菜单上方。
- 战斗回合数字与最大回合数合并为 `回合 12 / 40`，只做透明度反馈，不再放大数字挤入静态说明；临近上限变黄，到达上限变红。关闭清理动画及主/影子引用。
- 好友搜索原生输入框按实际输入底框定位，尺寸和坐标同时计入视口偏移；重复刷新先移除旧的StageText实例。
- 公会发布原生输入框按底框在舞台中的真实边界定位，修复全面屏/横向留边下的偏移。
- 奇遇标题栏采用原版深色九宫格，任务采用原版卡片与按钮贴图、金色/原版文字配色。加入原版奖励图标，随机奖励使用通用卡背并明确标注；标题/奖励/长状态文本自动适应宽度。
- 三个分类显示可领取数量，选中下划线移动、列表淡入；任务显示进度条、领取状态与按钮淡入。领取立即进入等待状态，保留单请求防重和离页回执失效规则。请求失败或过期状态回执时恢复按钮，再刷新数据，避免相同数据短路后一直禁用。
- 奇遇列表按标题区域和底部留白计算高度；卡片内图标、文字、按钮分别占独立区域，避免奖励说明覆盖领取按钮。

原有公告原生网页视口同步、背包底部过滤条与上阵窗口顶部过滤条继续保留，并纳入相关边界检查。附魔页保持730高的原版弹窗，四栏升级卡与符文操作区保留间距，不因假设的不存在的小尺寸弹窗重排。

## 验证边界

实际AS方法检查包含480/640/720宽的任务卡片、长奖励文本、分类切换不移动列表边界、失败领取重试、双击/离页回执、注册菜单与原生输入层级、个位/两位/40回合文本，以及含非零横纵偏移的原生输入映射。已有全面屏、公告、背包筛选、预设和装备魔法回归检查一并执行。

相关类实际编译为SWF，日志在 `build/ui-audit-103/compile/`。本轮没有重新打包/安装APK；读取了现有模拟器截图确认旧回合数重叠，但没有替换另一开发分支正在使用的安装包。370类是源码排查覆盖数，不代表已逐页完成实机截图验收；字体栅格、GPU动效、软键盘与所有账号状态组合仍需安装后的设备验收。
