# 奇遇 → 抓宝

新增奇遇第四页“抓宝”，使用原包海岛背景和12帧机器人动画。支持单抓、十连、分页查看完整奖池、领取累计奖励。

每抓100金砖，十连九折900金砖，每个上海自然日有1次免费机会。可直接十连，有免费机会时在九折价上再抵扣100金砖，实扣800，否则900。免费抓也计算抓宝进度。

每300抓一轮，显示计数回到0；下一轮重新获得各节点奖励。上一轮未领取的奖励保留为待领取份数，不占用下一轮进度。十连从295次开始时，结束显示5/300，并保留上一轮300次节点的奖励。每轮每个节点仅可领取一次，跨轮可以积攒多份。

| 节点 | 每轮奖励 |
| --- | --- |
| 10 | 500金砖、1000培养书 |
| 50 | 四色粉尘各500、德诺石500 |
| 100 | 橙色盖伦1张、六色天赋材料各300 |
| 300 | 艾克橙卡1张、5000金砖 |

先按类别概率抽取，再在该类别条目中等概率选择：材料60%、英雄卡20%、魂魄10%、装备10%。奖池从当前生效配置生成，涵盖1～6星内置英雄卡（包括皮肤卡）、英雄魂魄、普通装备及技能书、装备魂魄，以及金币、金砖、英雄积分、勋章、竞技印记、培养书、德诺石、各色粉尘和天赋材料、体力、碎片能量、宝箱及钥匙。NPC/召唤物和受专属装备获取规则限制的装备不进入随机奖池；不可用英雄也不会入池。本功能没有修改其他渠道的皮肤卡或专属装备规则。

服务端接口为 `user.zhuabao_info`、`user.zhuabao_draw`、`user.zhuabao_claim`。状态放在账号 `attrs.zhuabao` 中，与旧roulette活动独立。扣费、所有掉落、免费机会、计数和操作回执在同一SQLite事务中提交，背包不足时整次回滚。重发同一个actionID不会再次扣费或发奖。界面请求期间禁用按钮，移除页面后忽略迟到回包。
